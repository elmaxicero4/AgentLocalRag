Estructura del JSON Retornado por el Agente (`POST /api/ask`)

Diseñado con el estándar JSend Envelope: mensaje natural limpio, citas tipadas y metadatos separados.

{
  "success": true,
  "status": "success",
  "data": {
    "mensaje": "Hola. Según el Manual de Políticas de AgentLocalRag, el turno nocturno es de 8 horas, operando de 22:00 a 06:00.",
    "pregunta": "¿Cuál es la duración del turno nocturno?",
    "fuentes": [
      {
        "id": 1,
        "archivo": "manual_corporativo.txt",
        "documento": "manual_corporativo.txt",
        "seccion": "1. JORNADA LABORAL Y HORARIOS",
        "fragmento": "1.2. El equipo de soporte técnico opera en turnos...",
        "score": 0.3387,
        "relevancia_porcentaje": "33.87%"
      }
    ],
    "total_fuentes": 1,
    "tiene_fuentes": true
  },
  "metadata": {
    "modelo": "qwen2.5-coder:14b",
    "session_id": "default",
    "tiempo_respuesta_segundos": 3.98,
    "timestamp": "2026-11-03T16:08:01+00:00"
  },
  "error": null
}

Campos Principales para Frontend:

  • data.mensaje Texto natural limpio generado por el modelo 14B listo para renderizar en la burbuja de chat.
  • data.tiene_fuentes Booleano (true/false). Si es true, despliega el acordeón de citas. Si es false (tema fuera de alcance), no renderiza fuentes.
  • data.fuentes Array con documento, seccion, relevancia_porcentaje y el fragmento textual exacto.
  • metadata Metadatos de latencia (tiempo_respuesta_segundos), modelo activo (qwen2.5-coder:14b) y fecha ISO.
💡 Tip para React: Puedes desestructurar directamente con: const { data, metadata } = await res.json();
